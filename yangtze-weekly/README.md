# 长江生态保护与水生生物多样性周报

面向长江流域生态保护决策、科研布局与工程实施的开放式周度情报简报。

本项目重点追踪：

- 国家及长江流域政策、法规、规划和监管要求；
- 水生态、水生生物、鱼类资源、生态流量、栖息地和生物多样性监测评价标准；
- 重大生态修复、珍稀特有鱼类保护、河湖连通及水电生态调度项目；
- 涉水、能源和水电中央企业的生物多样性治理、TNFD/ESG披露与实践。

## 最新一期

- [2026年第6期：9月20—26日](reports/2026/2026-09-20_2026-09-26.md)：生态保护红线五年成效评估；“生态大坝”进入部级制度设计；县城黑臭水体与工业园区水污染攻坚计划原则通过。
