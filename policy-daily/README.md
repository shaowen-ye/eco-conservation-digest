# 生态环境资源政策跟踪与回溯

本栏目持续跟踪国内外生态、环境和自然资源治理的重要政策、法规、规划、监管制度、国际公约实施与重大管理行动，并回溯奠基性历史文件及其修订、替代和实施链。

## 阅读说明

- 按北京时间日期归档，每日文件内分 02:00、08:00、14:00、20:00 轮次增量更新。
- “最新动态”与“历史回溯”分列，历史材料不会包装为当日新政。
- 优先使用政府、立法机关、监管机构、国际组织和企业正式披露；一般宣传和纯科研成果不收录。
- 状态区分正式发布、征求意见、规划部署、阶段进展和待核线索。
