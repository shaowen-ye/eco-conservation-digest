# 生态保护动态速览 | Ecology & Conservation News Digest

This repository archives PDF issues of **生态保护动态速览**, a periodic digest of ecology and conservation news, policy updates, and research literature.

本仓库用于保存“生态保护动态速览”各期 PDF 报告。该速览定期搜集和整理生态保护、生态修复、生物多样性保护、自然保护地、气候与生态治理等相关动态，覆盖国内政策进展、国际机构动态、近期学术论文和经典高被引研究，提供要点摘要、中文解读、来源信息和原文链接，便于快速跟踪生态保护领域的最新进展。

## File Naming

Reports use a date-based filename:

```text
生态保护动态速览_YYYY-MM-DD.pdf
```

## Update Workflow

Reports are generated by the local OpenClaw workflow, normalized to PDF with clickable source links, and then uploaded here automatically.
